About

I'm a backend developer working primarily in Java and Spring Boot, with a focus on services that need to be reliable, observable, and easy to hand off — batch pipelines, integrations, and internal tools built with Spring Batch, MongoDB, and Oracle SQL.

Day to day that means owning the whole path from code to production: containerizing services with Docker, deploying on AWS, Kubernetes, and OpenShift, and wiring up delivery through Jenkins and Harness, with Splunk and SonarQube keeping an eye on quality and runtime health.

I'm an AWS Certified Solutions Architect – Associate, comfortable designing on the core AWS building blocks — EC2, S3, RDS, VPC, IAM, CloudWatch, and Lambda.
